      Complete Binary Tree & Index Math

      Every level before the last is completely filled, and the last level is filled from left to right with no gaps. In 0-indexed array A, parent(i) = ⌊(i − 1) / 2⌋ (for i > 0), left(i) = 2i + 1, and right(i) = 2i + 2.

      Min-Heap vs. Max-Heap

      In a Min-Heap every parent is ≤ its children (root is the minimum). In a Max-Heap every parent is ≥ its children (root is the maximum). In the pseudocode, “beats” means strictly < (Min-Heap) or strictly > (Max-Heap), so equal values never swap.

      Sift Up & Sift Down

      Insert places the new value at the next free slot A[n] and sifts it up toward the root. Extract removes A[0], moves the last element A[n − 1] to index 0, and sifts it down toward the smaller child (Min-Heap) or larger child (Max-Heap), with the left child winning ties.

      Why Build Heap Is O(n)

      Bottom-up heapify skips all leaves (at least half the nodes, which need 0 swaps) and sifts down only internal nodes from parent(n − 1) = ⌊(n − 2) / 2⌋ down to 0. Most internal nodes sit near the bottom and move only 1–2 levels, keeping total work linear (≤ 2n comparisons and < n swaps).
