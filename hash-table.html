    Modulo Hashing & Negative Keys

    Using ((k mod m) + m) mod m guarantees a valid bucket index in [0, m − 1] even for negative keys. Choosing a prime table size m (such as 7, 11, or 13) reduces clustering when keys share common factors.

    Load Factor (α = n / m) & Rehashing

    As α grows, chains lengthen in Separate Chaining and probe runs grow sharply in Linear Probing. Rehashing allocates a fresh table size and reinserts every live key, restoring O(1) expected time.

    Primary Clustering (Linear Probing)

    In Linear Probing, consecutive occupied slots merge into long runs. Any key hashing into a run must walk to the end of it, making the cluster even longer.

    Why DELETED Tombstones Matter

    Setting a deleted slot back to EMPTY in Linear Probing would break search chains for keys inserted later via collisions. A DELETED tombstone tells Search to keep probing while letting Insert reuse the slot.
