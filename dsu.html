    Disjoint Set Complexity & Properties

    Configuration / Operation Complexity Notes

    Keyboard shortcuts when focus is outside an input, control, or scroll region: Space play/pause, ←/→ step, Home reset.

    Parent Pointers & Representative Roots

    Each element x stores only its parent index parent[x]. Walking upward until parent[x] = x reaches the set’s unique representative root. Two elements belong to the same set if and only if find(a) = find(b).

    Why Union by Rank Bounds Tree Height

    Every root tracks a rank that upper-bounds its subtree height (it equals exact height only when path compression is off, because compression flattens paths without lowering ranks). Merging attaches the lower-rank root under the higher-rank root; only an equal-rank merge increases rank by 1 (ties break to the smaller root ID). Since rank rises from r−1 to r only by combining two rank-(r−1) trees, a tree of rank r contains at least 2r nodes by induction, keeping height ≤ ⌊log2 n⌋. With Union by Rank off, union(a, b) attaches rootA under rootB and ignores rank[].

    How Path Compression Flattens Chains

    During find(x), every visited node on the path to the root is re-parented directly to that root (parent[v] ← root). Future lookups on those nodes finish in a single hop. Combined with Union by Rank, m operations take O(m · α(n)) total time—effectively constant O(α(n)) amortised per operation, where α is the inverse Ackermann function (≤ 4 for all practical n).

    Real-World Uses (Connected Components & Kruskal’s MST)

    Union-Find tracks dynamic connected components in undirected graphs as edges are added, detects cycles in real time, and powers Kruskal’s Minimum Spanning Tree algorithm by sorting edges in ascending order of weight and adding an edge (uniting its endpoints) only when find(u) ≠ find(v) to avoid cycles.
